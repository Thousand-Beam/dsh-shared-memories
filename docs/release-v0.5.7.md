## v0.5.7

新会话又忘了自己叫什么。

查下来是继承规则写窄了。插件本来会让新会话继承本工作区「最近活跃」的人格，但宿主每开一个会话都会先落一行空壳人格（名字就是它自己的 id），空壳刚建、永远最活跃。于是新会话继承到的总是上一张空壳，你给它起的名字一直排在队尾，轮不到。

这版把顺序改了：**有名字的人格优先**，同样有名才比活跃度。已经在跑的老会话也会一起归位——下次它们出现在对话里时，会自动从空壳挪到你起的那个名字下面。

有一件事得说清楚：人格和记忆在插件里是同一个键。会话归位之后，它自己那份独立记忆就不会再跟着它走了，读到的是归位后那个人格的记忆。想保留某个会话的独立身份，给它单独起个名字就行。

测试 161/161。
