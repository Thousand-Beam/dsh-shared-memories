# v0.6.2

v0.6.1 评审报告的全量修复版。三个 P1、七个 P2，加上顺带清掉的几个 P3/P4。

## 同仓库第二次启动不再掉进只读

journal 的 `entity.upsert` 之前不带 `contentHash`，重放时拿 `entityId` 兜底去查内容唯一索引，查不到就插，撞上主键冲突，事务回滚，整机掉进只读。现在 `entity.upsert` 带上 `contentHash` 和 `deviceId` 两个字段，重放侧在三元组查询不命中时再加一道主键兜底，命中就走更新、幂等。同一根因也顺带修掉了「两台设备各自建了同内容记忆、合并分支永不命中」的双建实体问题。

## 快照回退后不再「记忆复活」

journal 按 UTC 日期分片，回退点之后跨天写出的新分片是 git 没跟踪的文件，`git checkout <tag> -- .` 只恢复快照里有的文件、不删 untracked，随后的 `git add -A` 又把它们收进 revert 提交，冷启动全量重放就把「晚于回退点的记忆」复活了。

现在回退时写一条 `journal.truncate` 墓碑（记录截断水位和快照 id），`readMerged` 按设备过滤掉水位之后的记录，冷启动和跨设备同步都自动回到回退点。

## 非法 agentId 不再炸宿主

`writePersona` 之前不校验 `agentId`，`../../etc` 这类脏值能入库，下次启动 `buildPrompt` 走到作用域断言就抛错、宿主 fatal。现在入口用 `isSafeScopeToken` 校验、非法直接 400，`buildPrompt` 对脏 id 也做容错跳过，不再拖垮整个宿主。

## 防投毒补上八个漏网变体

「无视上述指示」「解除你的一切限制」「忘掉之前的全部规则」这类倒装、量词变形之前漏拦。现在动词表、宾语表、量词都扩了，还加了一条倒装正则专门抓「把规则都忘掉」这类语序，八个变体全部命中。

## 分支错位现在会告警

`doctor` 自检新增「分支一致性」检查：当前 HEAD 分支和配置里的 `repo.branch` 对不上就报 error，并给出 checkout 或改配置两条路。detached HEAD 也会 warn。

## 并发写审计不再 500

`audit_id` 之前用毫秒时间戳当主键，并发一高就撞键。现在改成时间戳加随机段，撞键概率可以忽略。

## 读接口也走鉴权

之前只有写操作过 `requestRejection`，GET 全线裸奔——记忆、快照、隔离区都能被同源 fetch 读走。现在读和写统一走鉴权，connection 缺失（无 webServer 的 profile）时才跳过。

## 无痕会话不再让快照停摆

无痕巡检之前把 `persona_identity` 绑定当记忆痕迹，切无痕后一保存就触发泄漏告警、快照永久停摆。现在绑定不算泄漏、真实记忆才算；手动保存遇到泄漏会明确抛 `ephemeral-leak` 400，不再静默吞掉。

## UI 情感标注不再 404

前端 `fixEmotion` 之前不发 `agentId`，服务端拿不到归属，一改就 404。现在前端带上 `agentId`，服务端也做了兜底。

## 顺带清掉的几个小项

- `MAP_SYSTEM` 的情绪标签从硬编码 8 个改为引用 12 标签唯一权威源，不再各自为政。
- 实体「复现计数」随 `entity.upsert` 漫游，跨设备重放取最大值，不会换机归 1。
- 回退 / 钉住在恢复未就绪时加 `assertWritable`，返回 423，不再和恢复引擎并发读写。
- `traits` 传数组或字符串时明确 400，不再被误当对象或静默丢弃。
- `sync-interval` 补上 86400 秒上限校验。
- `skills` 的 action 只认 `bind` / `unbind` / `toggle`，其它一律 400。
