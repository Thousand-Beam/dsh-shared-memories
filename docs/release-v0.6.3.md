# v0.6.3

v0.6.2 评审报告的全量修复版。两个 P1、五个 P2，加上顺带清掉的几个 P3/P4。

## 回退墓碑补上上界，回退后新写的记忆不再被误删

上一版的回退墓碑只做了「水位以下截断」，漏了上界：回退点之后该设备新写的记录也被一并截断，重建的内容换机就丢。现在墓碑按窗口语义过滤——水位之前的丢、墓碑自身之后的保留，回退后继续写的内容照常漫游。

## 脏 agentId 流进技能绑定不再炸宿主

`POST /skills` 之前是异步 fire-and-forget，脏 `agentId` 进了作用域断言抛错，变成 unhandled rejection、宿主 fatal。现在入口同步校验，非法直接 400；三处写操作也都改成 `await`，返回的绑定列表是真实状态。

## 踩坑记录随 journal 漫游

`pitfall.record` 之前只写本地 SQLite、不写 journal，换机后这条坑完全消失；`pitfall.promote` 升格到 lesson / pattern 时内容也不漫游。现在新建坑写 `pitfall.record`、升格写完整字段，重放侧加了两个 case：新建幂等插入、升格只升不降。

## 死代码大扫除

- `Consolidator` 之前有配置没装配，纯死代码。现在挂进 24 小时节流定时器，合并判决真正生效。
- `memory/distill.ts` 的 `Distiller` 类只有 type import 引用，生产早就走 `host/distill` 的新管线。整文件删除，`/import` 的 `distill` 参数保留但标注已废弃。

## 全局检索真正全局

`listMemories` 之前 `global=1` 只写审计、查询还是按 agent 过滤，等于没实现。现在签发成功后查询不再带 agent 过滤。

## 快照回灌不再覆盖新画像

恢复时 journal 先全量重放，快照文件再回灌，而画像回灌之前无条件覆盖、时间戳还写成恢复时刻，旧快照画像压掉了新画像。现在画像 `updated_at` 走 MAX 语义、回灌传快照捕获时间，旧快照不会覆盖新数据。

## 防投毒再补四个漏网变体

「把这些规则都忘掉」「忽视之前所有指示」「清除你的一切规则」「略过之前的全部指令」四个变体之前漏拦。动词表补上「忽视 / 清除 / 略过」，量词补上「这些 / 那些」，四个变体全部命中。

## doctor 快照计数只数本机

多设备仓库里，快照堆积检查之前把别的设备的目录也数进去，误报「堆积」。现在按本机 deviceId 后缀过滤，只数自己的快照。

## 人格缺名字不再被抹回 agentId

`POST /persona` 之前缺 `name` 就用 `agentId` 兜底，改个 traits 或 age 就把精心起的名字抹掉了。现在缺 `name` 时先读库里已有的名字，读不到才用 `agentId`。

## 导入的踩坑项同时落踩坑表

`kind=pitfall` 的导入项之前只写时间树、不进踩坑表，坑不参与升格链、也不跨设备漫游。现在导入时同时调 `recordPitfall`，踩坑项完整进踩坑链。

## 顺带清掉的几个小项

- `traits` 的值必须是有限数值，传字符串或 `null` 明确 400，不再静默丢成空。
- `/identity`、`/session-policy`、`/import` 三个端点补上脏 `agentId` 校验，非法直接 400。
- 单条记忆正文加 8000 字符上限，超长正文不再挤占提示词窗口。
- `importer` 的 `audit_id` 追加随机段，同一毫秒重复导入不再撞主键。
- 快照 `manifest.json` 回写带 commit hash 后 amend 进同一提交，工作区不再留脏 manifest。
